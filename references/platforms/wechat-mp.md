# 微信公众号

## 硬限制（摘要）

- 标题 ≤ 64 字；作者约 ≤ 8 字；摘要 ≤ 120 字；正文 ≤ 50000 字  
- 封面常用 900×383（约 2.35:1）  
- SeedCast / 本 Skill 默认 **草稿**；群发/正式发表由用户在 mp 后台确认  

## 改写要点

- 开头 3 段内给出结论或价值点  
- 多用小标题；少用纯外链（外链能力依赖账号类型）  
- 摘要独立写，勿直接截标题  

## 检查清单

- [ ] 标题手机一屏可读（建议首条 ≤15 字展示友好）  
- [ ] 有封面方案或 cover 路径  
- [ ] 无未说明来源的敏感承诺
