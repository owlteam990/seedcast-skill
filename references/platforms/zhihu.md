# 知乎

## 体裁

| variant | 说明 |
|---|---|
| article | 写文章草稿（Skill 主推：专栏 API） |
| pin | 想法（桌面 Flow；Skill 暂未接） |
| question | 提问题（不做「回答某问题 ID」） |

## Skill 发布

- Cookie + `zhuanlan.zhihu.com/api/articles/drafts` 写草稿，不自动公开发表  
- 回执：`https://zhuanlan.zhihu.com/p/{id}/edit`  
- 桌面端仍可用 Flow（导入公众号 / 发布设置等）

## 改写要点

- 文章：清晰论证、小标题、少营销腔  
- 话题 1～3 个即可；封面可选但有图更好  

## 检查清单

- [ ] Cookie 有效（`accounts check --platform zhihu`）  
- [ ] 标题 ≤100 字、正文非空  
- [ ] 草稿编辑页可打开
